3. Examination Instructions

Phase 8.5: The examination timer starts when you enter the examination. The timer continues correctly after a page refresh because the examination end time is stored in the active browser session.
  1. Select the examination paper.
  2. Select the number of questions.
  3. Select the examination duration.
  4. Optionally choose a year and unit filter for Paper I or Paper II. Full Mock uses all eligible questions.
  5. Confirm NTA Exam Mode.
  6. Start the examination.
  7. Enter the examination.
  8. The countdown begins when the examination workspace opens.
  9. The timer remains active during navigation.
  10. Refreshing the page does not reset the timer.
  11. When the timer reaches zero, the examination workspace is locked. Final submission is available in this phase.
